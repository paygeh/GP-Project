# GP-Project
💇‍♀️ Salon Scheduling System

📌 Project Overview

The Salon Scheduling System is a student software development project designed to help salons manage appointments, clients, services, and scheduling in one convenient system.

The goal of this project is to create a simple and user-friendly scheduling application that reduces scheduling conflicts and makes it easier for both salon employees and customers to manage appointments.

🎯 Project Goals

* Allow customers to schedule appointments.
* Allow salon employees to view and manage their schedules.
* Keep track of customer information.
* Manage available salon services.
* Prevent scheduling conflicts.
* Provide an organized and easy-to-use scheduling experience.
* Demonstrate software development, database, and user-interface concepts learned in class.

✨ Features

Customer Management

* Add and manage customer information.
* View customer appointment history.
* Update customer contact information.

Appointment Scheduling

* Create new appointments.
* Select a salon service.
* Select an available date and time.
* Edit or cancel appointments.
* Help prevent double-booking.

Service Management

* View available salon services.
* Display estimated service durations.
* Add, edit, or remove services.

Employee Management

* Manage stylist/employee information.
* View employee schedules.
* Assign appointments to specific employees.
* Track employee availability.
